# Parth Agarwal – Portfolio

Source for my personal site: a visiting-card landing page and a portfolio of my creative and technical work.

**Live:** [parthagarwal.runs-on.dev](https://parthagarwal.runs-on.dev)

## What's here

- **Landing page** (`index.html`) – who I am, how to reach me, and my résumé
- **Works** (`portfolio/`) – films, designs, photos and code, with a tunable "mode" control that re-renders the page's type, colour and layout to match each kind of work
- **Work with me** (`freelance/`) – freelance page (in progress)

## Tech

Hand-written HTML, CSS and JavaScript – no framework or build step.

## Running locally

```bash
npx serve .
```
